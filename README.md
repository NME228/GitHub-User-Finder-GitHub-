GitHub User Finder
Автор: Нужин Матвей
Описание: Простая консольная программа для поиска пользователей GitHub и сохранения избранных профилей. Работает без сторонних библиотек — использует только встроенные модули Python.
Примеры использования: поиск пользователя с возможностью добавления пользователя в избранное, просмотр списка избранных пользователей.
Сценарий 1: поиск пользователя
1) Выберите 1 в меню.
2) Введите имя пользователя (например, octocat).
3) Программа покажет информацию о пользователе.
4) При желании добавьте его в избранное, ответив «да».
Сценарий 2: просмотр избранного
1) Выберите 2 в меню.
2) Программа выведет список всех избранных пользователей.
